The app opens to Home with no onboarding. Its interface is in English.

To review local play, open Round, select a fixture, choose an outcome and optionally enter a matching exact score, then save. Complete the training round to apply simulated results; view points and results on Home and in Profile. The personal leaderboard contains only the local player. Starting a fresh season requires confirmation.

Optional reminders request notification permission and schedule local notifications for open training fixtures. The small or medium widget shows local round progress and opens Round; it shares its projection with the app through an app group.

For leagues, enter a reachable server URL, create an account or sign in, then create a league or join with an invitation code. Save a prediction, refresh the round and standings, and view members’ answers after answers close. Sharing a code uses the system share interface. Local-network access is declared for league-server connections. The included development server defaults to localhost and is not a deployed service; a reachable configured server is required for league review. Server data and points are separate from the local season. Sign-in is required again after restarting the app.
